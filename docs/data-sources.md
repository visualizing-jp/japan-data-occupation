# データソース

職種別就業者数の探索ダッシュボードのための、データソース調査とデータ層の設計方針。
実装前の意思決定記録。調査日: 2026-09-04。軸は e-Stat API のメタ取得で確認済み。

## 1. 結論

職種 × 年 × 性 × 年齢 × 都道府県の一体表は存在しない。ビューごとに表を分ける。

| ビュー | 一次ソース | 統計表ID | 次元 | 指標 |
| --- | --- | --- | --- | --- |
| 時代 | 労働力調査 年平均 | `0003024269` | 職業×性×年（年齢「15歳以上」） | 就業者数・構成比 |
| 年齢 | 同上 | `0003024269` | 職業×性×年齢×年 | 就業者数・構成比 |
| 地域 | 国勢調査 時系列 | `0003410411` | 職業大分類×性×都道府県×調査年 | 就業者数・立地係数 LQ |

出典表記: 総務省「労働力調査」「国勢調査」（e-Stat 経由）。

## 2. 採用データセット（メタ実測）

### `0003024269` — 労働力調査（時代・年齢）

- 統計名: 労働力調査 基本集計　全都道府県 全国 年次
- 表題: 年齢階級，職業別就業者数（2009年～）-平成21年12月改定職業分類による
- 軸: 表章項目(1) × 職業(37) × 性別(3) × 年齢階級(17) × 地域(1=全国) × 年次(17: 2009–2025)
- 軸の積 32,079 / 公称件数 30,181（疎）
- 表章項目は「実数(人口)」。単位は万人（小数1桁の公表慣行）。配信では万人のまま置く。
- 性別コード: `0` 総数 / `1` 男 / `2` 女
- 年齢「15歳以上」（コード `00`）→ 時代ビュー。5歳階級（重複する合算行を除く）→ 年齢ビュー。

年齢階級の配信対象（左から若年）:

`15～19` `20～24` `25～29` `30～34` `35～39` `40～44` `45～49` `50～54` `55～59` `60～64` `65～69` `70～74` `75歳以上`

除外: `15歳以上`（総数）、`65歳以上`、`70歳以上`、`15～64歳`（合算行）。

職業: 総数 `000` + 大分類・中分類 36。大分類をグルーピング、選択単位は中分類を含む一覧。年齢ランキングは葉ノード（中分類がある大分類は中分類のみ）で非重複にする。大分類の合計は総数より数万人小さい残差がある（万人丸め／表に単独項目の無い分類不能相当）。

### `0003410411` — 国勢調査 時系列（地域）

- 統計名: 時系列データ 人口の労働力状態，就業者の産業・職業
- 表題: 職業（大分類），男女別就業者数及び人口構成比［職業別］（15歳以上就業者）－都道府県（平成17年～令和2年）
- 軸: 表章項目(2: 就業者数 / 人口構成比) × 職業大分類2015(13) × 男女(3) × 地域(47県) × 調査年(6)
- 地域に全国行は無い。全国値は47県の合計で作る（cube 先頭に `00000` を合成）。
- 調査年コード:
  - `2005000000` 2005年
  - `2010000000` 2010年
  - `2015000000` 2015年 / `2015000010` **2015年_不詳補完値**（採用）
  - `2020000000` 2020年 / `2020000010` **2020年_不詳補完値**（採用）
- 性別: `100` 総数 / `110` 男 / `120` 女
- 職業: `100` 総数、`110`–`220` が A–L（L=分類不能）。表示名から全角アルファベット接頭辞を落とす。

## 3. 指標

### 時代

就業者数（万人）と、職業総数に対する構成比。年齢調整は第一版では出さない。

### 年齢

選択年齢階級での職種ランキング＋構成比バー＋年齢横断スパーク。

### 地域 — 立地係数 LQ

\[
LQ = \frac{\text{県の当該職種構成比}}{\text{全国の当該職種構成比}}
\]

全国自身の LQ は定義上 1。色スケールは職種横断で固定（全国の 1/1.5〜1.5 倍）。
`分類不能の職業` は一覧に出すが地図の強調対象からは外す。

## 4. 配信ファイル

`scripts/build.ts` が `public/data/` に書く。

| ファイル | 次元 | 指標 | 辞書 |
| --- | --- | --- | --- |
| `era.json` | occ × sex × year | workers, share | occupations |
| `occ-age.json` | occ × age × sex × year | workers, share | occupations, ages |
| `geo.json` | occ × sex × year × area | workers, share, lq | occupations, areas |

cube 形式は `dims` + `measures`（行優先フラット配列）+ 辞書配列。欠測は `null`。
`share` / `lq` は小数4桁に丸める。

## 5. 注記（UIに短く出す）

- 2011年: 東日本大震災による労働力調査の調査影響。
- 職業分類は平成21年12月改定で接続。
- 国勢は5年おき・全数、労働力調査は標本推計。人数の横断比較はしない。

```
npm run fetch
npm run data
npm run verify
```

`ESTAT_APP_ID` は `.env` に置く（コミットしない）。生レスポンスは `data/raw/`（gitignore）。配信用 JSON は追跡する。
